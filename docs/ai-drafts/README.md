# Черновики ИИ, отклонённые на ревью

Здесь лежат первые варианты, которые сгенерировал ИИ, и почему они не пошли в прод.
Это не «музей ошибок ради галочки», а честный след процесса: два самых дорогих
решения в проекте родились именно из отказа от этих черновиков.

| Файл | Что это | Почему отклонён | Что вместо |
| --- | --- | --- | --- |
| `template-hero.tsx` | первый hero: градиенты, glassmorphism, «инновационная обжарка» | прямой запрет брифа, ноль фактов о клиенте, на мобильном не остаётся места живому контенту | `src/components/hero.tsx` — бумага, серифная типографика, фото ростера, расписание |
| `sqlite-store.ts` | хранение заявок в SQLite-файле рядом с приложением | на Vercel ФС read-only и ephemeral: запись упадёт, дедупликация между инстансами развалится | Telegram Bot API + память/Upstash Redis для дедупа, локальный JSONL только вне Vercel |

Подробности — в `README.md` (разделы 1 и 3) и `docs/ai-worklog.md`.
