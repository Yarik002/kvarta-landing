**Что внутри**
- Next.js 16 (App Router) + TypeScript + Tailwind CSS 4, без корзины и оплаты — заявка уходит менеджеру.
- Дизайн: бумага, серифная типографика, жжёная терракота, фото Unsplash, тексты от лица Ани и Дмитрия. Специально уходил от «сгенерированного» вида: никаких градиентов, glassmorphism и «инновационной обжарки».
- Форма: имя, телефон с интерактивной маской и строгой проверкой белорусских номеров (мобильные 25/29/33/44 + городские), интерес (подписка / разовый заказ / вопрос), комментарий.
- `POST /api/lead`: серверная валидация, дедупликация по номеру на 10 минут (включая двойной клик), honeypot и rate limit.
- Сквозная аналитика: UTM-метки, `yclid/gclid/fbclid`, referrer и страница входа уходят в теле заявки; first-touch живёт в `sessionStorage`.
- Заявки: Telegram Bot API (мгновенное уведомление + история в чате), дедуп-хранилище в памяти инстанса или Upstash Redis; файл/SQLite осознанно не использовал — на Vercel ФС read-only и ephemeral, обоснование в README.
- UX состояний: блокировка кнопки на время отправки, понятный успех, отдельный экран для дубля, ошибка с телефоном и Telegram.
- SEO/перф: OpenGraph-превью для мессенджеров, Schema.org, sitemap/robots, `next/image` с WebP/AVIF, локальные сабсеты шрифтов, `content-visibility` для секций ниже первого экрана.

**Честно о процессе** (подробнее — в README и `docs/ai-worklog.md`)
- ИИ ошибался, я это ловил: первым делом он предложил SQLite-файл для заявок — на Vercel это нерабочая история; сгенерировал шаблонный hero с градиентами и glassmorphism — отклонил по брифу; инлайн-CSS и SVG-шум ради «крафта» дали −20 баллов Lighthouse — убрал. Черновики, которые отклонил, лежат в `docs/ai-drafts/` — чтобы было видно, как принимались решения, а не только финал.
- Что делал сам: продуктовые и дизайн-решения, тексты и их тон, архитектура хранения, сценарии дедупа/UTM, ревью каждого этапа, ручные прогоны формы и Lighthouse.
- Что не успел: полноценная админка заявок (Postgres/статусы), личный кабинет подписки, реальные фото, A/B-тесты и дашборд по UTM, e2e в CI. Если нужно — приоритизирую под ваши задачи.
